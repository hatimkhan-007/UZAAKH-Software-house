# UZAAKH Software House

A modern and professional software house website built with **React**, **Vite**, **Tailwind CSS**, and **Framer Motion**. This project showcases a premium company portfolio with a clean UI, responsive design, smooth animations, and scalable architecture.

## 🚀 Features

- Modern Landing Page
- Responsive Design
- Dark & Light Mode
- Smooth Animations
- Company Portfolio
- Services Section
- Products Showcase
- Product Details Pages
- Pricing Plans
- Team Section
- Careers Page
- Blog Section
- Contact Page
- Authentication UI
- FAQ Section
- Testimonials
- Professional Footer
- 404 Page

## 🛠️ Tech Stack

- React.js
- Vite
- Tailwind CSS
- React Router DOM
- Framer Motion
- Lucide React
